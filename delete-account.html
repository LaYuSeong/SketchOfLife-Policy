SketchOfLife 계정 삭제 안내

SketchOfLife는 Google 로그인을 이용하며, 앱의 계정 인증에 Firebase Authentication을 사용합니다. 이용자는 SketchOfLife의 계정 및 관련 데이터 삭제를 요청할 수 있습니다.

중요: 이 요청은 SketchOfLife 서비스 계정에 관한 것입니다. Google 계정 자체나 Gmail, Google Drive 등 다른 Google 서비스 계정은 삭제되지 않습니다.

앱을 이미 삭제했거나 앱에 접속할 수 없는 경우에도 다음 절차로 요청할 수 있습니다.

  1. 아래 계정 삭제 요청 이메일 보내기 버튼을 누르거나, 안내된 주소로 직접 이메일을 보냅니다.
  2. 메일 제목은 SketchOfLife 계정 삭제 요청으로 작성합니다.
  3. 본문에는 앱 로그인에 사용한 Google 계정 이메일 주소와 계정 및 관련 데이터 삭제 요청이라고 적습니다.
  4. 운영자가 계정 소유 여부를 안전하게 확인한 후 관련 데이터 삭제 절차와 결과를 안내합니다.

2. 앱에서 회원 탈퇴하기

SketchOfLife 앱에서는 사용자 정보 화면을 통해 계정과 관련 데이터 삭제를 진행할 수 있습니다.

  1. SketchOfLife 앱을 실행하고 Google 계정으로 로그인합니다.
  2. 사용자 정보 → 회원 탈퇴를 선택합니다.
  3. 삭제 대상 데이터와 복구 불가 안내를 확인하고 탈퇴 진행을 누릅니다.
  4. Google 계정 선택 화면에서 기존에 로그인했던 Google 계정으로 재인증합니다.
  5. 계정에 연결된 데이터 삭제와 Firebase Authentication 계정 삭제가 완료되면 로그인 화면으로 이동합니다.

회원 탈퇴를 진행해도 Google 계정 자체는 삭제되지 않으며, SketchOfLife 계정과 관련 데이터만 삭제 대상이 됩니다.

  1. SketchOfLife를 실행하고 본인의 Google 계정으로 로그인합니다.
  2. 사용자 정보 → 회원 탈퇴를 선택합니다.
  3. 계정과 관련 데이터의 삭제 범위 및 복구 불가 안내를 확인하고 탈퇴 진행을 누릅니다.
  4. Google 계정 선택 화면에서 기존 SketchOfLife 로그인에 사용한 계정으로 재인증합니다.
  5. 앱이 삭제 작업을 완료하면 Firebase 인증 상태가 변경되어 로그인 화면으로 이동합니다.

3. 계정 삭제 시 처리하는 데이터

계정 삭제 요청 시 SketchOfLife에서 해당 계정과 연결해 보관하고 있는 정보를 삭제 대상으로 확인합니다. 실제 저장 위치와 삭제 가능한 범위에 따라 다음 항목이 해당할 수 있습니다.

  • 계정 정보: SketchOfLife용 Firebase Authentication 사용자 정보(UID 등) 및 앱에서 별도로 저장한 프로필 정보(있는 경우)
  • 일정·학습 기록: 일정 제목·메모·시간·장소, 학습 계획·진도, 사진 등 첨부 항목(실제로 저장한 범위)
  • 운동·신체 기록: 운동 종목·세트·중량·반복 횟수, 체중·체지방률 등 사용자가 입력한 체성분 기록
  • 러닝 기록: 러닝 날짜·시간·거리·페이스 및 위치 좌표에 기반한 이동 경로
  • 기타 기록: 여행 계획, 식물 관리 기록 등 이용자가 앱에 등록한 데이터

로컬 데이터 안내: SketchOfLife의 일정, 학습, 운동, 러닝 등 일부 기록은 사용자 기기 내부의 Room 데이터베이스에 저장됩니다. 앱 내 회원 탈퇴가 정상적으로 완료되면 해당 기기의 계정 관련 로컬 기록을 삭제하도록 처리합니다. 앱을 이미 삭제한 경우 운영자는 사용자의 기기 내부 데이터에 직접 접근할 수 없습니다. 앱 전용 내부 데이터는 일반적으로 앱 삭제 시 제거되지만, Android 백업 또는 별도 저장된 파일은 저장 방식에 따라 다르게 처리될 수 있습니다.

삭제 처리 기간: 앱에서 직접 회원 탈퇴를 진행하는 경우, Google 계정 재인증 및 데이터 삭제 절차가 정상적으로 완료되면 즉시 처리됩니다. 이메일을 통한 계정 삭제 요청은 계정 소유 확인이 완료된 날부터 7일 이내에 처리하며, 처리 결과를 요청자에게 이메일로 안내합니다.

삭제 후 보유하는 데이터: SketchOfLife 계정 삭제가 완료되면 Firebase Authentication 사용자 계정과 해당 기기의 앱 내 삭제 대상 기록을 삭제합니다. 운영자가 별도로 보관하는 사용자 기록은 없습니다. 다만 관련 법령에 따라 보관이 필요한 정보가 발생하는 경우에는 해당 법령에서 정한 기간 동안 보관한 뒤 삭제합니다.

관련 법령에 따라 보관이 필요한 정보가 있는 경우에는 해당 항목과 보관 사유·기간을 안내하고, 그 기간이 끝나면 삭제합니다.
