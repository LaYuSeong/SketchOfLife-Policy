SketchOfLife 계정 및 데이터 삭제 요청

SketchOfLife에서 생성한 계정과 관련 데이터를 삭제하는 방법을 안내합니다.

계정을 삭제하고 싶으신가요?

SketchOfLife는 Google 로그인(Firebase Authentication)을 사용합니다. 앱을 이용할 수 없는 경우에도 이 웹페이지를 통해 SketchOfLife 계정 및 관련 데이터 삭제를 요청할 수 있습니다.

계정 삭제 요청 시 Google 자체 계정이 삭제되는 것은 아닙니다. SketchOfLife에서 사용하는 Firebase 인증 계정과 서비스 관련 데이터를 대상으로 합니다.

1. 웹에서 삭제 요청하기

  1. 아래 계정 삭제 요청 이메일 보내기를 선택하세요.
  2. 요청 내용에 SketchOfLife 계정 삭제 요청이라고 적고, 앱에 연결한 Google 계정 이메일을 기재하세요.
  3. 운영자가 계정 소유 여부를 확인한 뒤, 확인 결과와 삭제 처리 방법을 안내합니다.

2. 앱에서 삭제 요청하기

앱을 사용할 수 있는 경우 다음 경로에서 회원 탈퇴를 진행할 수 있도록 안내할 예정입니다.

  1. SketchOfLife 앱을 열고 Google 계정으로 로그인합니다.
  2. [실제 앱 메뉴 경로: 예시 '설정 → 계정 → 회원 탈퇴']으로 이동합니다.
  3. 삭제 대상과 주의사항을 확인하고 탈퇴를 요청합니다. 보안을 위해 Google 재인증이 필요할 수 있습니다.

※ 운영자는 실제 앱에 회원 탈퇴 경로를 구현한 뒤 문구를 수정해야 합니다. 구현 전인데 이미 제공 중인 것처럼 표시하지 마세요.

3. 삭제 대상 데이터

계정 삭제 시 삭제 대상에는 실제로 SketchOfLife 계정과 연결되어 보관된 다음 정보가 포함될 수 있습니다.

  • SketchOfLife의 Firebase Authentication 계정 정보
  • 서버에 보관되는 경우 해당 계정과 연결된 일정·메모·학습·운동·러닝·체성분·여행·식물 기록
  • 서버에 보관되는 경우 해당 계정과 연결된 러닝 GPS 경로 및 첨부 데이터

기기 내부에만 저장된 데이터: 운영자가 해당 기기에 원격으로 접근해 삭제할 수 없는 경우, 사용자가 앱의 기록 삭제 기능을 이용하거나 Android 설정에서 앱 저장공간의 데이터를 삭제해야 할 수 있습니다. 단, 서버 또는 백업에 저장된 데이터는 별도로 처리해야 합니다.
